# J1 — Referral intake → case → matching request

## Problem
A referral is NAVORA's revenue intake, but a case only becomes billable care when the facts behind Swiss home-care financing are known: consent, residence (decides who pays residual financing), health insurer and insurance type, and medical order status. Today (#23) the case carries consent, region and requested services only. Matching can start for cases that can never be billed, and the gaps surface weeks later as rejected invoices.

## Users and journey step
Referrer (hospital discharge team, nursing home, GP, client or relative), NAVORA intake. Journey: Partneranfrage → Fall → Matching (`ARCHITECTURE.md` data flow).

## Outcome
A referral becomes a case that is *ready for care* in one sitting, and a matching request exists only for cases that can actually be delivered and funded.

## Acceptance criteria
- [ ] A referral converts to exactly one case, even when submitted twice; the case keeps a link to its source referral. *(delivered in #23, to confirm)*
- [ ] The case stores: municipality and canton of residence; health insurer and insurance type (KVG, IV, UV, MV, private, unknown); medical order status (`present`, `requested`, `not-required-A/C-only`); GP named or not; other providers active yes/no.
- [ ] A readiness check blocks *ready for matching* while any of these is missing: consent, residence, insurer and insurance type, care need with requested start. It returns the missing items with reasons, so the UI can show "why not ready".
- [ ] Missing non-blocking items (GP, other providers, language and access notes) become visible tasks on the case, not silent blanks.
- [ ] The matching request is created only by a server-side command once the case is ready; never from Operations.
- [ ] Every case state change is a logged command with who and why.
- [ ] Negative: a partner sees and submits only its own organisation's referrals; nobody outside intake and the assigned team sees insurer or order data.

## Out of scope
Automatic insurer checks, document upload beyond the medical order, contract and tariff management, partner portal polish.

## Constraints and references
KLV Art. 7a (OKP contributions A 76.90 / B 63.00 / C 52.60 CHF per hour, 2026), Art. 8a (needs assessment first). Since 1 July 2024 categories A and C can be provided without a medical order; B still needs one; the GP must be informed. Residual financing depends on residence and on the provider's municipal mandate. Related: D-9 (legal basis at intake), D-11 (pilot canton), D-15 (clinical sign-off of the checklist).
