## Problem
FE-052 (founder, 2026-11-07) says NAVORA has no demonstrably viable pilot yet. Every later block acceptance relies on CI results. Today those results are not yet trustworthy, for five reasons (inventory 2026-11-07, `PRODUCT_BLOCKS.md` §1):
- the same commit has been both green and red (13 `recovery/main` commits);
- merge commits had no complete run of their own;
- agents cannot test locally;
- the repository is not protected;
- database privileges are checked only in part.

The watcher (`scripts/agents-coordination/plan.mjs`) picks the highest-ranked approved and unstarted item. That item was NH-A1 (#968, a feature, frozen). So the coordination layer and the founder's order pointed different ways.
