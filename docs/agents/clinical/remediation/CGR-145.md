# Remediation plan: CGR-145 (the qualification matrix loosens CR-007 for FaGe) with CGR-147 and CGR-148

**Findings:** `cra` CGR-145, Clinical Governance Report 2026-11-06 21:50, **advisory (S1)** before real data; refined by CR-179 to CR-183 in the 22:35 report (matrix v0.2), together with **CGR-148** (advisory S1: the check on every path and at visit start) and **CGR-147** (advisory S1 before Phase B: NH-EXT). Placed by the PO as **QUAL1** (`briefs/QUAL1.md`, approved 2026-11-06 22:30 for synthetic data only; issue #931). Engineering: ADR-163, migration 0120 (part 1).

**Risk:** inside the matrix a `fage_efz` may be responsible for Bst. b activities with a delegation. That is looser than today's rule (KLV-B minutes and needs assessment only for a `registered_nurse`, CR-007, CR-164). If the loosened rule reached a real organisation, or if any path (proposal, hand assignment, take, swap, cover, start) skipped it, a person without the required grade, evidence or delegation could be planned for an activity (H-04, H-33). A self-confirmed profile or an agent's output treated as evidence would do the same (FE-039).

**Affected code and data (part 1, IMPLEMENTED in the PR, CI decides):** new `organizations.simulation`; `qual_activities`, `qual_matrix_versions`, `qual_matrix_cells`, `member_qualification_evidence`, `qual_delegations`, `qual_delegation_revocations`, `visit_activities`; `private.qual_evidence_state`, `private.qual_check`, `private.qual_may_perform`, `private.qual_may_delegate`; commands `confirm_my_qualification`, `record_delegation`, `revoke_delegation`; reader `visit_qualification_check`; `private.aig1_prohibited_target` (class `qualification`). No existing table row, rule or path changes in part 1.

**Steps:**
1. (IMPLEMENTED, part 1) The matrix rule exists only in an organisation marked `simulation` (no grant, fixture or migration only). Everywhere else `private.qual_may_perform` returns `private.may_perform_visit` (CR-007/CR-164) unchanged. pgTAP 120 proves both (CGR-145 (e)).
2. (IMPLEMENTED, part 1) Every matrix cell is PROPOSED and versioned; "?" and any open question (K-2, K-3, L-1) are never allowed (CR-179).
3. (IMPLEMENTED, part 1) `verified` evidence is refused for any request user, any command and any API role, and outside a simulation organisation; a member's confirmation is `self_confirmed` and never counts (CR-181, FE-039). Expired and contradictory evidence count as absent.
4. (IMPLEMENTED, part 1) A delegation is recorded only by a verified `nurse_hf_fh` with a verified practice licence, for a D cell of the delegate's verified grade (CR-176a), one case, one activity, fixed dates; it stops counting when revoked, ended, or when its delegator or supervisor lapses ("Überprüfung nötig", nothing deleted). No agent can aim at it (AIG1).
5. (PLANNED, part 2, after PR #934 merges) Every assignment path calls `private.qual_may_perform` and refuses with the activity and reason: PLAN3 proposal and confirm, PLAN2 series, hand assignment, take, swap (both sides), COVER1 `accept_cover`, ABS1 re-assignment; and again at visit start (CGR-148, QUAL1-10, QUAL1-17). pgTAP per path: the same (member, visit) the check refuses is refused there.
6. (PLANNED, part 2) Lapse releases future visits to the team as "Voraussetzung abgelaufen" (CR-051 pattern, QUAL1-4); contradictory evidence notifies the professional role once (QUAL1-5).
